# 腾讯云部署指南（CloudBase 静态托管 · 免备案）

> 适用于本项目：**纯静态网站**，不需要服务器、不需要构建。
> 上传文件已整理在：`D:\AI Design\sicau-timeline-deploy\`（8 个文件，共 277KB）
> 也提供打包版：`D:\AI Design\sicau-timeline-deploy.zip`

## 为什么选 CloudBase 而不是 COS

| 方案 | 默认域名能看网页？ | 要备案吗 | 结论 |
|---|---|---|---|
| **CloudBase 静态托管** | ✅ 自带 HTTPS 域（*.tcloudbaseapp.com） | ❌ 不需要 | ✅ 推荐 |
| COS 静态网站 | ❌ 2024 年后新建桶默认域名不支持网页预览 | ✅ 绑自定义域名必须 ICP 备案 | 未来有域名再说 |
| EdgeOne Pages | ✅（*.edgeone.app） | 国内加速要备案 | 备选 |

## 操作步骤（控制台，全图形化）

### 第 1 步：登录腾讯云
1. 打开 https://cloud.tencent.com/ ，微信扫码登录
2. 若提示未实名认证：先在「账号信息 → 实名认证」完成（个人认证即可，微信/人脸 1 分钟）

### 第 2 步：创建云开发环境
1. 进入控制台 → 搜索「云开发 CloudBase」→ 打开「云开发控制台」
2. 点「创建环境」（或"开通环境"）
3. 环境名称填：`sicau-timeline`
4. 套餐类型：选**按量计费**（有免费额度，最低消耗）；地域选「上海」（文档标注静态托管支持上海）
5. 等待约 1-2 分钟环境初始化完成，记下**环境 ID**（形如 `sicau-timeline-1gxxxxxx`）

### 第 3 步：上传网站（二选一）

**方式 A：新建部署（推荐）**
1. 左侧菜单「静态网站托管」→「网站部署」→「新建部署」
2. 选择「上传代码包 / 项目文件夹」
3. 上传 `sicau-timeline-deploy` 文件夹（或 `sicau-timeline-deploy.zip`）
4. 关键配置：
   - 项目名称：`sicau-timeline`
   - **安装命令：留空**（纯静态项目）
   - **构建命令：留空**
   - **构建输出目录：`.`**（当前目录）
   - 部署路径：`/`
5. 点「部署」，等 1 分钟左右完成

**方式 B：文件管理直传（更简单）**
1. 「静态网站托管」→「文件管理」→「上传文件夹」
2. 选择 `sicau-timeline-deploy` 整个文件夹上传（会自动保持目录结构）

### 第 4 步：拿默认域名并验证
1. 「静态网站托管」→「基础配置」→ 复制**默认域名**（形如 `https://sicau-timeline-1gxxxxxx.tcloudbaseapp.com`）
2. 浏览器打开 → 应该能看到「土管2025级 时间轴」+ 开场动画
3. 手机上再打开一遍确认

- 把腾讯云地址写进 README 和 docs

## 以后更新数据的两条路

1. **手动**：改好 `data/events.js` 后，在控制台「文件管理」里重新上传这一个文件（几秒钟）
2. **自动（可选）**：安装 Node.js + CloudBase CLI（`npm i -g @cloudbase/cli`），之后一条命令同步：
   ```powershell
   tcb login
   tcb hosting deploy D:\AI Design\sicau-timeline-deploy -e <环境ID>
   ```
   需要的话告诉我，我帮你配好（你只需浏览器登录一次）。

## 常见问题

| 症状 | 处理 |
|---|---|
| 打开域名 404 | 确认 `index.html` 传到了**根目录**（不是套了一层文件夹） |
| 样式/字体没加载 | 确认 `assets/`、`data/` 目录结构一起传了 |
| 更新后页面没变 | CDN 缓存，控制台上传会自动刷缓存；或强刷 Ctrl+F5 |
| 提示流量超出 | 免费额度 5GB/月（约十几万次访问）；个人使用很难超 |
| 想用自己的域名 | 需要域名 + ICP 备案（约 1-2 周），备案完成后在「基础配置 → 自定义域名」绑定 |
